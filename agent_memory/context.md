# 项目上下文

## 产品

- 暂定名：序升（Sequence / Ascend）
- 形态：面向 iPhone 竖屏的移动端优先 PWA，体验接近原生应用。
- 核心理念：每完成一件让自己变好的小事，就获得经验；所有行为汇总到同一个角色。
- 核心循环：今日任务 → 即时完成反馈 → 经验与属性成长 → 等级 / 连续奖励 / 成就 → 现实奖励。

## MVP 范围

- 五页：首页、主线、支线、成就、角色。
- 四维属性：力量、生命、智慧、魅力。
- 本地存储，不含登录、云同步、服务端与多人功能。
- 优先做深“完成任务并成长”，月报先提供数据入口，不做复杂导出。
- 主线任务由用户自行添加、编辑和停用，仅归属力量、生命、魅力；支线记录统一增长智慧。
- 主线经验采用固定强度档位：微行动 10、标准 20、训练 40、挑战 60 XP，避免自由填写经验造成失衡。
- 当前减脂 15 斤作为成就中心下的二级 Boss 讨伐页呈现，不增加第六个底部导航。

## 设计方向

- 五个页面现已统一采用暖白测绘纸、炭黑行动舱、荧光黄信号、细线刻度与硬切角；首页保持海报式绝对构图，其余页面使用适合操作和滚动的档案式纵向布局。
- 首页命题为“个人行动档案”，不是深色仪表盘；首屏顺序为品牌状态、等级、右侧大角色、底部拇指区行动舱和固定导航。
- 主线、角色、成就、支线已按顺序完成视觉迁移；各页保留自己的任务职责，不复制首页绝对定位海报结构。
- 首页继续使用原创“序升者”分层角色作为视觉锚点，并保留克制的呼吸、眨眼、耳动与任务奖励反馈。
- 角色页使用一体化静态素材 `assets/live2d/profile_character_integrated_v2.png`，不再把补全身体与首页旧头颈图层硬拼；390×844 从狼耳到双脚完整显示，等级、称号与四维属性采用边缘扫描 HUD 围绕人物。首页使用干净头颅 `cranium_earless_refined_v2.png`，并以原头颅 alpha 轮廓作为 CSS mask，保留分层微动态坐标与眨眼兼容性。

## 技术方向

- 无框架静态 PWA：HTML、CSS、JavaScript、Web App Manifest、Service Worker。
- 数据保存在 localStorage，结构预留版本号，便于后续迁移。
