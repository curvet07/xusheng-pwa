# 问题与风险

## 当前风险

- 环境中缺少 `~/.codex/templates/agent_memory/` 模板目录，无法按仓库说明原样复制；已建立职责相同的最小中文文件。
- MVP 使用 localStorage，清除浏览器数据会丢失记录；云同步留到后续版本。
- iOS 对 PWA 安装提示和 Service Worker 更新策略有平台限制，需要真机最终确认。
- Live2D 分批生成的独立小图层无法稳定还原母版：头发、脸、手臂和肩甲存在比例与坐标漂移。禁止继续通过 CSS 缩放硬拼；必须回到同一母版原位切层或由画师制作分层 PSD。
- Live2D 前景遮挡层禁止使用横向矩形裁片；角色头部旋转或下沉时会形成“削下巴”效果。应沿衣领实际轮廓制作遮罩，并为下巴和颈部保留运动安全区。
- 头部层不能与身体层分别执行独立位移动画；头部必须继承躯干呼吸变换，再围绕颈根旋转，否则颈部会呈现脱节感。
- 更换头颅底图后，所有表情帧必须由同一底图重新生成；禁止跨版本复用眼周补丁，否则细微眼位差会造成眨眼跳帧。
- 首页角色脸部周围禁止叠放竖向进度尺或状态面板；信息条应与面部保持明确安全间距。
- 角色页四维 HUD 只能贴近舞台边缘并使用短引导线；不得扩大成覆盖人物的属性卡片，也不得遮挡面部、狼耳、手部和双脚。
- 角色页补全身体与首页分层头颈不是同一母版，禁止再次混合装配；角色页只使用一体化静态全身素材，首页才使用可眨眼的分层头部。
- 首页更换基础头颅时必须同步更新半闭与全闭帧；旧眨眼素材包含整张旧头，不能作为纯眼周补丁叠加到新版脸上。
- 减脂进度当前由用户手动填写“累计已减斤数”，不是医疗级体重分析；最佳进度与当前趋势分开，回升不会回收奖励。
- 本轮自动化手机浏览器因本机 Chromium 进程启动限制未能完成；已完成静态引用、语法和设计检测，但新增 / 停用任务与 Boss 记录仍需在真机或可用浏览器补一次端到端验证。

## 已处理

- 设计文档曾错误保留“只有首页迁移、其余四页仍为旧深色系统”的过渡期描述；已按当前五页统一实现更新 `DESIGN.md` 与 `.impeccable/design.json`。
- 收尾审查发现页面标题上方存在模板化眉题，已统一移除；日期等真实状态信息保留。
- Service Worker 缓存版本已提升至 `xusheng-v2`，确保新增样式文件进入离线缓存。
- 已将前景高领的矩形裁片改为带中央 U 形安全区的轮廓遮罩，消除头部微动时的下巴横切。
- 启动遮罩样式只识别 `is-hidden`，脚本曾错误添加 `is-done`，导致应用一直显示“正在同步角色状态”；已统一状态名，并增加 2.5 秒容错退出与脚本缓存版本参数。
- 首页角色头部原比例与高领叠加后颈部露出不足；已保持颈根锚点不变，将完整头部组缩小并上移，避免单独移动脸、耳或眨眼帧造成分层错位。
- 首页左侧下颌与颈部贴合处存在旧绿幕抠图色溢；自动像素重绘会改变人物身份，未采用。现通过单独收窄颈部层并降低残余绿色饱和度，将污染边缘藏入下颌轮廓，同时保持脸部资产不变。
- CSS 滤镜无法真正移除接缝污染，已新增确定性的边缘清理脚本，输出收缩 2px 透明边缘的颈部素材和头颅遮罩；首页改为直接引用新资产并加入独立缓存版本参数。
- 头颅遮罩不能对整张 alpha 使用形态学腐蚀：旧绿幕遮罩在脸部内部含半透明区域，整体腐蚀会把它扩大成背景穿透的白色缺口。已撤回错误头颅遮罩，恢复原始完整遮罩；只保留独立颈部素材的边缘清理。
- 旧 Service Worker 使用全量缓存优先，普通刷新可能持续返回旧 HTML/CSS，造成修复看似未生效。现改为页面、CSS、JS 联网优先，断网时才回退缓存；注册时跳过 HTTP 缓存并在控制权切换后自动刷新一次。
